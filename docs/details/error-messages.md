# エラーメッセージ一覧

[← 要件定義書に戻る](../requirements.md)

過去の設計用E-xxx/I-xxxコードはAPIで返していない。以下は現行コードの文言と発生箇所。
UIがAPIの文言を常にそのまま表示するとは限らない。

## 入力検証

登録・ログインのNotBlank/Size/Pattern/Email文言は [入力チェック仕様](input-validation.md) を参照。
DTO検証エラーは400で `status, errors[{field,message}]`、投稿パラメータのConstraintViolationは
400で `status, message` を返す。複数制約に違反した場合、どの文言が選ばれるかの順序は保証しない。

## 業務・システムエラー

| HTTP | 文言 | 発生箇所・条件 |
| --- | --- | --- |
| 409 | このメールアドレスは既に使用されています | 登録メール重複 |
| 409 | このユーザー名は既に使用されています | 登録username重複 |
| 409 | この表示名は既に使用されています | 登録displayName重複 |
| 401 | メールアドレスまたはパスワードが正しくありません | ログイン認証失敗 |
| 401 | リフレッシュトークンが無効です | refreshの不正トークン・猶予超過の再利用等 |
| 401 | リフレッシュトークンの有効期限が切れています | refreshの期限切れ |
| 404 | 投稿が見つかりません | 投稿詳細・いいね・コメント作成/一覧等で対象投稿なし |
| 403 | この投稿を編集する権限がありません / この投稿を削除する権限がありません | 他人の投稿を編集 / 削除 |
| 404 | コメントが見つかりません | コメントなし、またはpostIdとcommentIdの組合せ不一致 |
| 403 | このコメントを削除する権限がありません | 他人のコメントを削除 |
| 400 | 自分自身をフォローすることはできません | 自己フォロー |
| 409 | 既にフォロー済みです | 重複フォロー |
| 400 | フォローしていません | 未フォローの解除 |
| 404 | ユーザーが見つかりません | プロフィール・フォロー等の対象ユーザーなし |
| 403 | このプロフィールを編集する権限がありません | 他人のプロフィールを編集 |
| 400 | 検索キーワードを入力してください | 空白のみの検索q |
| 400 | `{名前} パラメータは必須です` | 必須リクエストパラメータ欠落 |
| 400 | 画像はJPEG・PNG・GIF形式、5MB以内でアップロードしてください | 投稿画像のMIME・サイズ検証 |
| 400 | 画像は JPEG・PNG 形式、5MB以内でアップロードしてください | アバターのMIME・サイズ検証 |
| 400 | 画像の保存に失敗しました | アップロードされたファイルのストリーム読み込み失敗 |
| 400 | 画像のアップロードに失敗しました。AWS設定を確認してください: `{詳細}` | S3StorageServiceの保存失敗。末尾は例外の内容に依存 |
| 500 | 予期しないエラーが発生しました | ハンドルされない例外（DB制約違反等を含む） |

上記の業務例外は原則 `{"status":数値,"message":"文言"}`。
認証フィルターの未認証応答は `sendError(401,"Unauthorized")` で、このJSON形式を保証しない。
いいねの重複追加・未いいね削除は204で成功し、「既にいいね済み」「いいねが見つからない」というエラーは返さない。

## UI固有の表示

| 文言 | 条件 |
| --- | --- |
| パスワードが一致しません | 登録画面の確認パスワード不一致 |
| ユーザーが見つかりませんでした。 | 検索結果0件（200の空配列でありAPIエラーではない） |
| 保存に失敗しました | プロフィール保存失敗。APIの詳細文言はこの文言で置き換わる |
| 投稿の取得に失敗しました。 | Homeのタイムライン取得失敗 |

プロフィールの表示名・自己紹介の長さエラーをAPIが専用文言で返す仕様は未実装。
画面固有の再試行文言・表示条件の正は `frontend/src/pages/` と `components/` の現行コード。
